# HTML5 e CSS3 — Módulo 05

Este módulo dá continuidade aos estudos de **HTML5 e CSS3**, focando em **layouts modernos** e na organização de elementos na página com **Flexbox** e **Grid Layout**.

Durante os exercícios, são trabalhados conceitos como **containers flexíveis, alinhamento, distribuição de espaço, grids, áreas e posicionamento**, além da aplicação desses conhecimentos em um projeto prático de portfólio.

---

## 📚 Conteúdos abordados

### 📦 Flexbox

* `display: flex`;
* `flex-flow`, `flex-direction` e `flex-wrap`;
* `justify-content`;
* `align-items`;
* `align-content`;
* `align-self`;
* `flex`;
* `flex-basis`;
* `flex-grow`;
* `flex-shrink`;
* Centralização horizontal e vertical;
* Menu responsivo com Flexbox;
* Conteúdo flexível (alternância entre mídia e texto).

### 🔲 Grid Layout

* `display: grid`;
* `grid-template`;
* `grid-template-columns` e `grid-template-rows`;
* `repeat()`;
* Unidade `fr`;
* `gap`;
* `place-items` e `place-content`;
* `grid-auto-rows`, `grid-auto-columns` e `grid-auto-flow`;
* `grid-column` e `grid-row`;
* `grid-column-start/end` e `grid-row-start/end`;
* `grid-area`;
* Criação de layouts com topo, menu, conteúdo principal, lateral e rodapé.

### 🎨 Organização e boas práticas

* Separação de estilos em arquivos CSS;
* CSS específico para mobile com `media` no `<link>`;
* Variáveis CSS (`--variavel`);
* Organização de projetos em pastas (`estilos`, `scripts`, `imagens`);
* Ícones com Font Awesome.

## 💻 Projetos práticos

Além dos exercícios, este módulo também contém um projeto que aplica os conhecimentos estudados de forma mais prática.

### 🧑‍💻 Projeto Portfólio

Projeto de um portfólio pessoal com seções de **perfil, skills, formação e projetos**, utilizando **HTML, CSS e JavaScript**.

Conceitos aplicados:

* Estruturação de páginas;
* Menu de navegação com âncoras;
* Rolagem suave entre seções;
* Tema claro e escuro com alternância por botão;
* Preferência de tema salva com `localStorage`;
* Variáveis CSS para as paletas de cores;
* Cards de projetos com imagens;
* Ícones com Font Awesome;
* Organização em pastas e arquivos separados.

## 🎯 Objetivo do módulo

O objetivo deste módulo é ampliar os conhecimentos de **HTML5 e CSS3**, avançando para a criação de layouts mais flexíveis e organizados.

Ao longo dos exercícios e do projeto, são praticados recursos importantes para:

* distribuir elementos em uma dimensão com Flexbox;
* criar layouts em duas dimensões com Grid;
* controlar alinhamento e espaçamento;
* posicionar elementos em áreas do grid;
* adaptar menus e conteúdos para telas menores;
* organizar projetos de forma profissional;
* aplicar os conhecimentos em um projeto prático.

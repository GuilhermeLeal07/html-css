# HTML5 e CSS3 — Módulo 03

Este módulo dá continuidade aos estudos de **HTML5 e CSS3**, aprofundando principalmente a utilização de imagens de fundo, posicionamento de elementos e criação e estilização de tabelas.

Durante os exercícios, serão trabalhados conceitos importantes para a construção de páginas mais estruturadas e visualmente organizadas, dando continuidade aos conhecimentos adquiridos nos módulos anteriores.

## 📚 Conteúdos abordados

### 🖼️ Imagens de Fundo

* Imagens como plano de fundo;
* `background-color`;
* `background-image`;
* `background-repeat`;
* `background-position`;
* `background-size`;
* `background-attachment`;
* Propriedade `background`;
* Gradientes como fundo;
* `background-size: cover`;
* Posicionamento de imagens;
* Centralização de elementos.

### 📍 Posicionamento de Elementos

* `position: relative`;
* `position: absolute`;
* Posicionamento de elementos;
* Sobreposição de elementos;
* `transform`;
* Centralização de elementos;
* Controle de posicionamento dentro de containers.

### 📊 Tabelas

* Estrutura básica de tabelas;
* `<table>`;
* `<tr>`;
* `<td>`;
* `<th>`;
* `<thead>`;
* `<tbody>`;
* `<tfoot>`;
* `rowspan`;
* `colspan`;
* `scope`;
* Bordas;
* Alinhamento de conteúdo;
* Espaçamento;
* Estilização de tabelas;
* Organização semântica de tabelas.

## 📂 Exercícios

## 🎯 Objetivo do módulo

O objetivo deste módulo é aprofundar os conhecimentos de **HTML5 e CSS3**, avançando na construção e estilização de páginas.

Ao longo dos exercícios, serão praticados recursos importantes para trabalhar com **imagens de fundo, posicionamento de elementos e tabelas**, desenvolvendo maior controle sobre a estrutura e apresentação das páginas.

# HTML5 e CSS3 — Módulo 02

Este módulo dá continuidade aos estudos de **HTML5 e CSS3**, aprofundando principalmente a utilização do CSS e a criação de estilos mais personalizados para as páginas.

Durante os exercícios, serão trabalhados conceitos relacionados a **cores, gradientes, fontes, seletores, pseudo-classes, pseudo-elementos e modelo de caixas**, além da organização de elementos utilizando as chamadas *Grouping Tags*.

## 📚 Conteúdos abordados

### 🎨 Cores e Gradientes

* Representação de cores por nomes;
* Códigos hexadecimais;
* RGB;
* HSL;
* RGBA;
* Gradientes com `linear-gradient()`;
* Configuração de fundo com CSS.

### 🔤 Fontes e Textos

* Famílias de fontes;
* Tamanhos de fonte;
* Medidas absolutas e relativas;
* Peso e estilo das fontes;
* Shorthand `font`;
* Alinhamento de textos;
* Recuo de parágrafos;
* Google Fonts;
* Fontes externas;
* `@font-face`.

### 🎯 Seletores Personalizados

* Seletores por `id`;
* Seletores por `class`;
* Diferenças entre `id` e `class`;
* Agrupamento e reutilização de estilos;
* Aplicação de múltiplas classes.

### 🖱️ Pseudo-classes e Pseudo-elementos

* Pseudo-classes;
* `:hover`;
* `:visited`;
* `:active`;
* Pseudo-elementos;
* `::before`;
* `::after`;
* Seletores de elementos filhos.

### 📦 Modelo de Caixas

* Elementos `box-level`;
* Elementos `inline-level`;
* `width` e `height`;
* `border`;
* `padding`;
* `margin`;
* `outline`;
* Sombras;
* Bordas personalizadas;
* `border-image`.

### 🧱 Agrupamento e Estrutura Semântica

* `header`;
* `nav`;
* `main`;
* `section`;
* `article`;
* `aside`;
* `footer`;
* Organização de conteúdo utilizando elementos semânticos;
* Criação de estruturas básicas de páginas.

## 🎯 Objetivo do módulo

O objetivo deste módulo é avançar dos conceitos básicos de CSS para uma utilização mais organizada e personalizada dos estilos, desenvolvendo uma melhor compreensão de como os elementos HTML podem ser selecionados, estilizados e estruturados.

Ao final do módulo, teremos uma base mais sólida para começar a trabalhar com **layouts, responsividade e projetos completos em HTML5 e CSS3**.

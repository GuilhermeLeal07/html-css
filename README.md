# HTML & CSS

Este repositório reúne meus estudos de **HTML5** e **CSS3**, desenvolvidos durante minha formação em Desenvolvimento Front-end.

O objetivo deste projeto é construir uma base sólida nos principais conceitos do desenvolvimento web, documentando minha evolução por meio de exercícios, desafios e pequenos projetos organizados de forma profissional.

Todo o conteúdo foi estruturado para representar minha jornada de aprendizado, preservando o contexto de cada etapa e aplicando boas práticas de organização, documentação e versionamento.

---

# 📖 Sobre o repositório

Este repositório foi criado com o objetivo de registrar minha evolução no desenvolvimento Front-end desde os primeiros contatos com HTML e CSS.

Os projetos aqui presentes representam diferentes momentos do meu aprendizado, começando pelos conceitos fundamentais e evoluindo gradualmente para páginas mais completas e estruturadas.

Sempre que possível, os exercícios são organizados e revisados para melhorar aspectos como:

- organização do código;
- legibilidade;
- HTML semântico;
- estruturação do CSS;
- acessibilidade básica;
- documentação;
- padronização de projetos;
- utilização do Git e GitHub.

O objetivo não é modificar completamente os projetos originais, mas organizá-los seguindo boas práticas e mantendo fidelidade ao conhecimento adquirido durante cada etapa dos estudos.

# 📂 Organização do repositório

Cada módulo possui seu próprio README explicando os conteúdos abordados, enquanto cada exercício também conta com uma documentação individual contendo seus objetivos, conceitos estudados e melhorias realizadas.

Exemplo da estrutura:


# HTML5 e CSS3 — Módulo 04

Este módulo dá continuidade aos estudos de **HTML5 e CSS3**, avançando para recursos utilizados na construção de páginas mais completas, interativas e adaptáveis a diferentes dispositivos.

Durante os exercícios, são trabalhados conceitos como **iframes, formulários, envio de dados, Media Queries e responsividade**, além da aplicação desses conhecimentos em projetos práticos.

---

## 📚 Conteúdos abordados

### 🖼️ Iframes

* `<iframe>`;
* Incorporação de páginas externas;
* Incorporação de páginas internas;
* Utilização de `src`;
* Utilização de `name` e `target`;
* Conteúdo alternativo para iframes;
* Controle de largura e altura;
* Incorporação de conteúdos como páginas, vídeos e mapas.

### 📝 Formulários

* `<form>`;
* `<input>`;
* `<label>`;
* `action`;
* `method`;
* `GET` e `POST`;
* `autocomplete`;
* Campos de texto;
* Senhas;
* E-mail;
* Números;
* Datas;
* Radio buttons;
* Checkboxes;
* Select;
* Textarea;
* Botões;
* Validação de campos;
* `<output>`;
* Envio de dados para arquivos PHP.

### 📱 Media Queries

* `@media`;
* Media Queries para diferentes dispositivos;
* `media="screen"`;
* `media="print"`;
* Orientação `portrait`;
* Orientação `landscape`;
* Diferentes tamanhos de tela;
* Estilos específicos para impressão;
* Adaptação de páginas para diferentes dispositivos.

### 📐 Responsividade

* Layouts adaptáveis;
* Responsividade para celulares;
* Responsividade para tablets;
* Responsividade para computadores;
* Responsividade para telas maiores;
* Imagens específicas para diferentes dispositivos;
* Alteração de estilos conforme a largura da tela;
* Menu responsivo;
* Adaptação de elementos da página.

## 💻 Projetos práticos

Além dos exercícios, este módulo também contém projetos que aplicam os conhecimentos estudados de forma mais prática.

### 📱 Projeto Redes Sociais

Projeto que utiliza **HTML, CSS e iframe** para simular a navegação de diferentes redes sociais dentro de uma interface baseada em um dispositivo móvel.

Conceitos aplicados:

* `<iframe>`;
* `target`;
* `name`;
* Links;
* Imagens;
* Estruturação de páginas;
* CSS;
* Organização de múltiplas páginas.

### 🔐 Projeto Tela de Login

Projeto de uma tela de login responsiva, utilizando diferentes recursos de HTML5 e CSS3.

Conceitos aplicados:

* Formulários;
* Campos de e-mail;
* Campo de senha;
* Validação de campos;
* `required`;
* `minlength`;
* `maxlength`;
* `autocomplete`;
* Media Queries;
* Layout responsivo;
* Ícones;
* Organização de CSS.

## 🎯 Objetivo do módulo

O objetivo deste módulo é ampliar os conhecimentos de **HTML5 e CSS3**, avançando da criação de páginas básicas para estruturas mais completas e adaptáveis.

Ao longo dos exercícios e projetos, são praticados recursos importantes para:

* incorporar conteúdos externos e internos;
* criar formulários;
* trabalhar com diferentes tipos de campos;
* compreender o envio de dados;
* adaptar páginas para diferentes dispositivos;
* criar layouts responsivos;
* aplicar os conhecimentos em projetos práticos.

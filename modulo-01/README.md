# Módulo 01 — Primeiros passos com HTML5

Este módulo reúne os primeiros exercícios do meu estudo de **HTML5** e marca o início da minha jornada no desenvolvimento Front-end.

O foco desta etapa foi compreender a estrutura básica de uma página web, conhecer as principais tags da linguagem e desenvolver familiaridade com a criação de documentos HTML seguindo boas práticas desde o início.

Os exercícios foram organizados e documentados para representar minha evolução durante o aprendizado, preservando a proposta original de cada atividade e aplicando melhorias relacionadas à organização, legibilidade e documentação.

---

# 📖 Sobre o módulo

Neste módulo foram estudados os conceitos fundamentais do HTML5, responsáveis por servir de base para o desenvolvimento de páginas web.

Ao longo dos exercícios, foram apresentados desde a estrutura mínima de um documento HTML até recursos como imagens, hierarquia de títulos, ícones, formatação de texto e introdução ao HTML semântico.

Cada exercício representa uma etapa do aprendizado e demonstra a evolução gradual dos conhecimentos adquiridos.

---

# 🎯 Objetivos de aprendizagem

Ao concluir este módulo, os principais objetivos foram:

- Compreender a estrutura de um documento HTML5;
- Criar páginas utilizando marcação semântica;
- Organizar corretamente títulos e parágrafos;
- Inserir imagens e ícones em páginas web;
- Trabalhar com listas e formatações básicas de texto;
- Desenvolver boas práticas de organização do código;
- Utilizar Git e GitHub para versionamento dos projetos.

---

# 🧠 Conceitos abordados

Entre os principais conteúdos estudados estão:

- Estrutura básica do HTML5
- Hierarquia de títulos
- Parágrafos
- Quebras de linha
- Caracteres especiais
- Emojis
- Inserção de imagens
- Favicons
- Diferenças entre HTML4 e HTML5
- Formatações de texto
- Citações
- Código-fonte
- Listas ordenadas e não ordenadas
- Introdução aos links
